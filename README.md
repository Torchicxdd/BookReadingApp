### Instructions for running the app:
#### Set Up Android Studio:
* Ensure that Android Studio is properly installed and configured on your computer.

#### Choose an Emulator or Physical Device:
##### Using an Emulator in Android Studio:
* Select a resizable device as your emulator to ensure the app displays correctly.
* You can create a resizable device under Device Manager in Android Studio.
##### Using a Physical Tablet:
* Connect the tablet to your computer:
  * Preferred method: Use a USB cable for a stable connection. 
  * Alternatively, you can connect the tablet wirelessly if configured in Android Studio. 
* Ensure the tablet is in developer mode and USB debugging is enabled.
  * Step 1: Enable Developer Mode
    * Open Settings on your Android tablet.
    * Scroll down and tap About tablet (it might be under System).
    * Find and tap Build number (usually located towards the bottom).
    * Tap Build number 7 times quickly. You should see a message saying "You are now a developer!".
  * Step 2: Enable USB Debugging
    * After enabling Developer Mode, go back to Settings.
    * Scroll down and tap System.
    * Tap Developer options (this menu will now appear after enabling Developer Mode).
    * Find and toggle on USB debugging.
  * Step 3: Confirm USB Debugging
    * Plug your tablet into your computer using a USB cable.
    * A prompt will appear on the tablet asking if you allow USB debugging. Tap Allow.
    * Now your tablet is ready for USB debugging.

#### Run the App:
* Open the app project in Android Studio.
* Select your emulator or connected device from the dropdown menu in the toolbar.
* Click the Run button to deploy the app.

#### Important Notes for School Computers:
##### If running the app on a school computer:
* We discovered that when we try to run the app on the tabled from the school computers it causes the app to crash when the user tries to download a book.
  * We did not know how to fix this issue, since the app seemed to work perfectly fine when Maara ran it on the table using our her computer.
* So instead, use the resizable emulator since we tested it and that seems to work fine.
